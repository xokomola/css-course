## CSS course Background

- This semester is quite interesting because of the next developments
    - students starting this semester have a more diverse background than before, f.i. coming from other specialisations than software engineering.
    - Students will get a general FICT diploma, so they each can have their own individual skills as their own personal profile.
- The impact of AI on the field of SW engineering is profound, and consequences are not cristalised yet.
- These developments above must lead to a semester, and learning outcomes, which must be flexible and be able to accommodate diverse student skills and profiles. A solution is, to find common aspects which play a role, and keep playing a role in a SW engineers future. So what will be common for all junior SW developers
	- you have to be able to operate in an environment which is uncertain both in domain (requirements) and technologies being used.
	- you have to be able to create SW products of good quality which fit the problem you are solving.
	- you have to be able to work together with existing SW environments, and make sure the solutions are maintainable.
	- you have to be able to act professionally
- You have to steer your personal development.
- Domains will become different, technologies will evolve, companies will change, so it makes sense to focus on acquisition of skills which allow our students to navigate their careers after their education. This means making always making justified choices, which can be validated.
- To be able to create an environment which enables this, each student will create it's own personal development plan (PDP), which describes the activities and product of the student, and how it maps to LO's of this semester. See [[Clarifications Learning Outcomes]]
- Because there will be a large individual part assigned in this PDP, there will be only 1 project: a group project for an external company. The rest of the time will be spent on personal excursions/experiments/investigations. We call these flavours.
- Because students not only work on their own, we encourage (and even mandate), sharing their investigations with others (students, groups, companies, teachers, class).
