This is the development repo for the **Fontys Complex Software Systems Course** that starts Spring 2026.

In principle any text- or Markdown-editor (or GitHub's own browser editor) can be used to edit, we prefer using [Obsidian](https://obsidian.md) as our authoring tool and some Obsidian features are used that may not be supported by other tools.

Overview pages:

- [[Modules]] outline structure for course (to use when manually creating course outline)
- [[Pages]] an overview of page metadata, also for each course sections separately

Obsidian plugins used:

- List Callouts (for coloring list items with a single character, quick notes)
- Fit (for one button commit to GitHub repository

Install any plugins that you prefer or that the maintainers of the course agree on.
